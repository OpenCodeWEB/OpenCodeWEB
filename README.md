# OpenCodeWEB — opencodeweb.pages.dev

> **All open-source projects in one place** — flagship stack (OS, AiA, GDBx, DSGx, GDMx, MCP, A2A, GunX, UI) + every org repository, live from the GitHub API. **Free, MIT, `Dev` default.**

**Repo:** `github.com/OpenCodeWEB/OpenCodeWEB` · **Live:** `https://opencodeweb.pages.dev`

## Dev

```bash
# local preview
npx wrangler pages dev public
# deploy production
npx wrangler pages deploy public --project-name opencodeweb --branch Dev --commit-dirty=true
```
